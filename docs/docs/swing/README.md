# DWC Look and Feel for Swing

A BBj application can use both WebUI and DWC screens. WebUI displays Swing controls, so a form using the default Swing look and feel can look out of place next to a DWC screen. The DWC Look and Feel for Swing brings the fonts, colors, buttons, and focus outlines on the WebUI side closer to DWC. You can also use it in a standalone Java Swing application.

The visual match is **best effort**. Swing and DWC draw their controls differently, and BBj draws some details itself, such as menu-button arrows. You can use the same light or dark palette across the application and still see small differences when moving between screens.

<a href="https://cdn.webforj.com/dwc-swing-laf/0.2.0/dwc-swing-laf.jar">Download the DWC theme JAR (0.2.0)</a> · Java 21 or newer · Both palettes and the Inter fonts are included.

## Try it with a form you can run

The example in this guide asks for a delivery email. Press **Save** with the field empty to show its validation message. Enter an address and press **Save** again to clear the message and show a confirmation. The example keeps the value in memory for the current session.

<img src="./swing/files/bbj-saved.png?v=11943d8145" width="386" alt="BBj WebUI showing the delivery email and the confirmation below Save">

| Where you want to run the form | What you will do |
| --- | --- |
| BBj WebUI | Save the example as **Delivery.bbj**, create a client classpath and register your own application in Enterprise Manager. Then open the link generated by your server. [Set up BBj in Enterprise Manager](swing/bbj.md). |
| Java Swing | Save the example as **Delivery.java** and run it with the theme JAR. [Install and run the form](swing/getting-started.md). |

In DWC Dark, the same form uses the dark field, button and confirmation colors.

## Apply it to your own screens

- To change **every screen**, select a palette, set the primary color or choose a font. [Appearance and motion](swing/themes.md).
- To change **one control**, give it a client property. For example, make a save button primary or mark a single field invalid. [Client properties by control](swing/client-properties.md).
- To change **window behavior**, choose dialog decorations and decide where keyboard focus is drawn. [Dialogs and keyboard focus](swing/limitations.md).
